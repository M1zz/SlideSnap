# 장표스냅 1.0.3 릴리즈 노트

## App Store "이번 버전의 새로운 기능" (한국어, 그대로 사용 가능)

위젯으로 더 빠르게 촬영하고, 흩어진 발표를 하나로 모을 수 있게 됐어요.

• 홈 화면·잠금화면 위젯 — 탭 한 번이면 장표스냅 카메라가 바로 열려요. 회의실에 들어가며 잠금화면에서 곧바로 촬영을 시작할 수 있어요.
• 여러 발표 합치기 — 따로 찍힌 발표들을 하나로 모을 수 있어요. 목록에서 여러 개를 골라 합치면 장표가 순서대로 이어 붙어요.
• 촬영 화면이 더 부드러워졌어요 — 장표를 잡아주는 네모가 부드럽게 따라가고, 자동 촬영이 너무 빠르게 연속으로 찍히지 않도록 간격을 넉넉히 뒀어요.
• 피드백 보내기가 더 잘 전달돼요 — 전송이 막혀도 메일로 자연스럽게 이어져요.
• 자잘한 개선과 안정성 향상.

의견은 언제든 앱 안 '피드백 보내기'로 들려주세요. 감사합니다 🙏
