# 장표스냅 1.0.2 릴리즈 노트

## App Store "이번 버전의 새로운 기능" (한국어, 그대로 사용 가능)

가져온 사진이 제대로 인식됐는지 한눈에 확인할 수 있게 됐어요.

• 인식 실패 표시 추가 — 장표 모서리를 찾지 못해 보정 없이 원본 그대로 저장된 장표에는 썸네일에 느낌표 배지가 붙어요. 해당 장표를 열어 모서리 조정으로 직접 잡아주면 배지가 사라져요.
• 보내주신 피드백이 개발자에게 더 빠르게 전달되도록 내부 시스템을 개선했어요. 남겨주신 의견은 하나하나 직접 읽고 있어요.
• 자잘한 개선과 안정성 향상.

의견은 언제든 앱 안 '피드백 보내기'로 들려주세요. 감사합니다 🙏
