# 장표스냅 1.0.1 릴리즈 노트

## App Store "이번 버전의 새로운 기능" (한국어, 그대로 사용 가능)

잠금화면에서 더 빨라진 장표 캡처, 그리고 한눈에 보기 좋아진 목록으로 돌아왔어요.

• 잠금화면 위젯 추가 — 잠금화면에서 위젯만 누르면 카메라가 바로 열려요. 강의 중 급하게 찍어야 할 때 앱을 찾을 필요가 없어요.
• 그리드 보기 추가 — 발표를 썸네일 카드로 한눈에. 목록/그리드는 버튼 하나로 전환되고 선택이 기억돼요. 목록에도 미리보기 썸네일이 생겼어요.
• 빈 발표 자동 정리 — 장표가 하나도 없는 발표는 알아서 정리돼 목록이 깔끔하게 유지돼요.
• 자잘한 개선과 안정성 향상.

의견은 언제든 앱 안 '피드백 보내기'로 들려주세요. 감사합니다 🙏
