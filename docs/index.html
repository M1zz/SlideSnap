장표스냅 SlideSnap

수업 슬라이드를 찍으면, 반듯하게 펴서 복습용 PDF로.

주요 기능

🟩

실시간 장표 감지

화면 속 슬라이드 모서리를 실시간으로 잡아 초록 브래킷으로 알려주고, 잡히면 자동으로 촬영합니다.

🗂️

자동 발표 묶기

연달아 찍은 장표를 하나의 발표로 자동으로 묶어 정리합니다.

🖼️

사진에서 가져오기

이미 찍어둔 강의 사진도 불러와 자동 보정해 담을 수 있어요.

🔍

텍스트 검색 (OCR)

장표 속 글자를 온디바이스로 인식해 키워드로 바로 찾습니다.

📄

복습용 PDF

한 장·두 장·네 장 레이아웃으로 번호가 매겨진 PDF를 만듭니다.

✋

손쉬운 정리

드래그로 순서 변경, 길게 눌러 삭제·공유까지.

자주 묻는 질문

장표를 어떻게 촬영하나요?

앱을 열면 바로 카메라가 뜹니다. 슬라이드를 화면에 맞추면 모서리가 초록색으로 잡히고, 그 상태에서 셔터를 누르거나 자동 촬영으로 담깁니다. 슬라이드가 바뀌면 자동으로 다음 장을 촬영합니다.

여러 장이 왜 하나의 "발표"로 묶이나요?

5분 이내에 이어서 촬영하면 같은 수업으로 보고 하나의 발표에 모읍니다. 목록에서 제목을 눌러 이름을 바꿀 수 있습니다.

이미 찍어둔 사진을 넣을 수 있나요?

네. 목록 화면의 ＋ → 사진에서 가져오기 또는 발표 안의 메뉴에서 사진을 여러 장 선택하면 자동 보정 후 담깁니다.

장표 속 글자를 검색할 수 있나요?

목록 화면 상단 검색창에 키워드를 입력하면, 인식된 장표 텍스트와 제목에서 검색해 해당 장표로 바로 이동합니다. 텍스트 인식은 모두 기기 안에서 이루어집니다.

PDF로 어떻게 내보내나요?

발표 안의 공유 메뉴에서 PDF로 내보내기를 고르고 레이아웃(한 장/두 장/네 장)을 선택하세요. 공유 시트에서 "파일에 저장"으로 저장하거나 다른 앱으로 보낼 수 있습니다.

장표 순서를 바꾸거나 지우려면?

그리드에서 장표를 길게 눌러 드래그하면 순서가 바뀝니다. 길게 누르면 나오는 메뉴에서 개별 삭제·공유가 가능하고, 선택 모드에서는 여러 장을 한 번에 삭제할 수 있습니다.

내 데이터는 어디에 저장되나요?

모든 사진과 정보는 기기 안에만 저장됩니다. 서버로 전송하지 않으며 계정도 필요 없습니다. 자세한 내용은 개인정보 처리방침을 참고하세요.
